# SSH Honeypot Lab

A simple Python-based honeypot designed to simulate an SSH server and capture attacker connection attempts.

## Objective

The goal of this project is to build a basic honeypot capable of detecting and logging malicious traffic such as SSH scans and brute-force attempts.

## Features

- Detects incoming connections
- Logs attacker IP addresses
- Captures SSH handshake data
- Simulates an SSH server
- Supports attack simulation with tools like Nmap and Hydra

## Technologies Used

- Python
- Linux (Ubuntu)
- Kali Linux
- Nmap
- Hydra

## Learning Outcomes

- Understanding honeypot architecture
- Simulating cyber attacks in a controlled lab
- Capturing attacker behavior
- Analyzing connection logs
